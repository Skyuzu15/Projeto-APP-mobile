Aplicativo mobile para monitoramento inteligente de colheita, focado em operações com conexão instável.

## Tecnologias Utilizadas
- **Frontend:** React Native (Expo)
- **Backend:** Node.js + Express
- **Upload:** Multer (Base64) + Axios
- **Armazenamento Local:** AsyncStorage (Offline First)

## Funcionalidades (Tech Forge)
- Cadastro e login (Admin vs Operador)
- CRUD de Cargas (Criar, Transferir, Receber)
- Upload de imagem da carga/nota fiscal
- Painel de exceções para o coordenador

## Como rodar o projeto
1. **Backend:** `cd rastrolote-backend` -> `npm install` -> `node server.js`
2. **Frontend:** `cd rastrolote-app` -> `npm install` -> `npx expo start`
